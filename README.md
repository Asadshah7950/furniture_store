# Furniture Store App

A Flutter e-commerce style furniture application with Firebase Authentication.
Users can register, sign in, browse furniture items by category, search products,
add items to cart, place orders, and view notifications.

## Project Owner

- Asad Ali Shah

## Clone Repository

Use this link to clone the project:

```bash
https://github.com/Asadshah7950/furniture_store.git
```

## Features

- Firebase email/password authentication (register and login)
- Product listing with search and category filtering
- Product detail screen with ratings and descriptions
- Add to cart and cart item management
- Checkout and order placement flow
- Orders history screen
- In-app notification list for cart/order events

## Tech Stack

- Flutter (Dart)
- Firebase Core
- Firebase Authentication
- GetX (state/reactive utilities)

## Requirements

- Flutter SDK (3.x recommended)
- Dart SDK (bundled with Flutter)
- Firebase project configured for your target platforms
- Android Studio or VS Code with Flutter extensions

## Setup Instructions

1. Clone the repository.
2. Move into the project folder.
3. Install dependencies.
4. Configure Firebase for Android/iOS/Web as needed.
5. Run the application.

```bash
git clone https://github.com/Asadshah7950/furniture_store.git
cd furniture_store
flutter pub get
flutter run
```

## Firebase Configuration

This project uses Firebase and already includes generated config files such as:

- `lib/firebase_options.dart`
- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist` (if configured)

If you want to connect to a different Firebase project, regenerate Firebase
configuration using FlutterFire CLI and replace the existing config files.

## Project Structure

- `lib/main.dart`: Main app UI, navigation, cart, checkout, orders, notifications
- `lib/firebaseauth.dart`: Firebase authentication controller
- `lib/firebase_options.dart`: Firebase options generated by FlutterFire
- `assets/`: Product images and static assets
